# Portafolio

Sitio estatico generado desde `proyectos.py`.

- Editar textos o sumar proyectos en `proyectos.py` (imagenes en `site/img/`, en WebP).
- Generar: `python3 build.py`
- Publicar: `npx netlify deploy --prod --dir site`

Regla: todo anonimo. Sin nombres de clientes ni de la empresa; capturas con datos de ejemplo.
